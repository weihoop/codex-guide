# Codex Prompt 示例

## 只读项目分析

```text
请只读分析当前仓库，不要修改文件。输出技术栈、入口、测试命令、发布流程和主要风险。
```

## 安全审查

```text
请审查当前分支的安全风险，重点关注密钥泄露、命令注入、路径遍历、权限绕过和日志敏感信息。
```

## 文档同步

```text
请更新 docs/INDEX.md，让它包含所有新增 Markdown 文件。不要修改其他正文。完成后运行链接检查。
```

## Bug 修复

```text
请复现并修复这个 bug：<描述>。
要求：先定位根因，再写或更新测试，最后最小化实现。输出验证命令和结果。
```
